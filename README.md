# BaseProject_

A clean and simple C++ base project made for following my tutorials and building your own features step by step.

## About the Projects

### BaseProject
`BaseProject` is the clean starting point used throughout my tutorials.

You can use it to:
- Follow along with the tutorial series
- Add your own features
- Experiment with C++
- Learn how an external project is structured
- Build your own project from the base

### BaseProject_Maotaw
`BaseProject_Maotaw` is my actively developed external project.

This version contains the features we build throughout the tutorials and will continue receiving new features, improvements, fixes, and optimizations.

Current examples include:
- Box ESP
- Skeleton ESP
- Healthbar
- Armor Bar
- Radar
- Snaplines
- Trails
- Custom colors
- Outlines
- ESP distance
- Menu themes
- Config saving
- And more

## Getting Started

1. Download or clone the repository.
2. Open the Visual Studio solution.
3. Select **x64**.
4. Build the project.
5. Follow the tutorials to understand, modify, or extend the code.

If a game update changes the required offsets, update them before rebuilding.

## Free to Use

The project is completely free and anyone can use it, modify it, learn from it, or build their own features on top of it.

If you are following my YouTube tutorials, I recommend starting with `BaseProject` and adding each feature yourself so you understand how everything works.

## Purpose

This repository is provided for **programming, learning, research, and educational purposes**.

The main goal is to help people learn C++, Windows programming, external project structure, rendering, memory concepts, and how larger projects can be organized.
